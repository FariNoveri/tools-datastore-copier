# Roblox DataStore Copier

Dokumentasi untuk kode aplikasi versi **1.0.0**. Untuk panduan project, cara instalasi, kredit, dan lisensi, lihat [README utama](../README.md).

## Menjalankan dari folder ini

```powershell
python -m pip install -r requirements.txt
python app.py
```

Browser akan terbuka di `http://127.0.0.1:5000`. Jalankan `python app.py --help` untuk opsi lainnya.

## Pengujian

```powershell
python -m unittest discover -s tests
```

Riwayat perubahan versi ini ada di [docs/CHANGELOG.md](./docs/CHANGELOG.md).
